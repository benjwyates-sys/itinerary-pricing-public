# Dubrovnik sample data

A practice dataset for trying the tool end to end without touching anyone's real rates.
Everything here is invented. The *shapes* are what matter — they're modelled on how
supplier rate sheets actually arrive.

You don't need Excel. These are real `.xlsx` files, generated by the same library the
tool reads them with, and they open fine in Numbers, Google Sheets or LibreOffice.
`csv-copies/` holds a plain-text version of every sheet if you just want to read them.

## The files

| File | What it's for |
|---|---|
| `Dubrovnik_Costing_2026.xlsx` | The rate sheet. Two regions: Dubrovnik (19 rows) and Split & Hvar. |
| `Trip_Sample_Dubrovnik.xlsx` | An itinerary to price. Worded the way an agent types, not the way the sheet reads. |
| `Trip_Sample_Dubrovnik_PRICED.xlsx` | A trip already priced by hand. This is the `/verify` test. |
| `build_samples.py` | Regenerates all three. Edit it if you want to make the sheet nastier. |
| `build_reference_catalog.py` | Shortcut: builds a correct catalog so you can skip `/map`. |

## Two ways to use it

**The real test** — do the whole flow as an operator would: `/profile`, then `/map Dubrovnik`,
then `/verify`, then `/cost`. This exercises the mapping conversation, which is the part
most likely to be awkward and the part you can't judge any other way.

**The shortcut** — `uv run python samples/build_reference_catalog.py` builds a known-good
catalog so you can jump straight to `/cost` and `/verify`. Useful for a quick look, and
it doubles as a worked example of what correct catalog entries look like.

## What each row is testing

The rate sheet is deliberately awkward in specific ways:

| In the sheet | What it exercises |
|---|---|
| Title block on rows 1–3, merged band on row 5, real headers on row 6 | Header detection. The tool should offer you **both** row 5 and row 6 and let you pick — not silently guess. |
| Old Town Walking Tour — **Private Guide** vs **Small Group** | Two near-identical names. It must not confuse them. |
| Transfer **DBV → Old Town** vs **Old Town → DBV** | Same words, opposite direction, same price. The classic way to quietly bill the wrong leg. |
| Two rows each for Old Town Private, Elafiti, both transfers | Tiers expressed as extra rows rather than columns. |
| `per group` vs `per person` in the Unit column | Whether it multiplies by party size or not. Getting this backwards on a group transfer is a 5× error. |
| Sea Kayaking with a PM Supplement | A time-of-day surcharge, applied per person. |
| Konavle with a Peak Supplement | A seasonal rate. Peak is 15 Jun – 15 Sep. |
| Cooking Class, "Billed for 4 minimum" | A minimum billable party size — a party of 2 still pays for 4. |
| Private Yacht Charter, "Not available 15 Aug" | A blackout date. |
| Ston Oysters, rate typed as `€85` | A rate stored as text rather than a number. |
| Bespoke Photography, rate `on request` | Something genuinely unpriceable. It must refuse, not guess. |
| Blank row 13 | A gap splitting the data into two blocks. |

## The answers

Both of these have been checked against the engine, so a disagreement means something
is wrong — not that the sample is approximate.

**`/verify` on the sample priced trip: all 7 lines match, total €1,728.00.**

| Line | Rule | Amount |
|---|---|---|
| Transfer DBV → Old Town, 4 pax | per group, 4–8 tier | 68.00 |
| Old Town Walking Tour — Private Guide, 4 pax | per group, 1–6 tier | 180.00 |
| Elafiti Islands Cruise, 4 pax | per person, 95 × 4 | 380.00 |
| Konavle Wine Tasting, 4 pax, 14 May | shoulder season, 78 × 4 | 312.00 |
| Cooking Class, 4 pax | per person, 110 × 4 | 440.00 |
| Cable Car, 4 pax | per person, 27 × 4 | 108.00 |
| Sea Kayaking, 4 pax, PM | (48 + 12) × 4 | 240.00 |

**`/cost` on the sample trip (5 travellers):** two lines price themselves immediately
because the wording matches the sheet exactly — Game of Thrones (€190) and Trsteno
(€60). The other nine should stop and ask you. Once you've resolved them, the total is
**€2,241.00**, with two lines correctly refusing:

- **Private yacht charter on 15 August** — blackout date.
- **Bespoke photography session** — the rate is "on request".

And two worth checking closely, because they're where silent errors hide:

- **Cooking class, 2 travellers → €440**, not €220. The minimum billable party is 4.
- **Konavle on 2 July → €460**, not €390. That date is peak season, so the supplement applies.

## What counts as a bug

**Not a bug:** being asked to confirm a match. Asking is the design — it only fills a
price in automatically when the wording matches exactly or you've confirmed that phrasing
before. On a first run against unfamiliar wording, expect to be asked about most lines.

**Not a bug:** a line refusing to price. That's the engine declining to invent a number.

**A bug:** any number that is confidently wrong. Also: a line vanishing from the output
with no mention, a question you can't answer by looking at the sheet, or a total that
disagrees with the tables above.

## Regenerating

```
uv run python samples/build_samples.py
```

Edit `build_samples.py` to make the sheet nastier —
that's the fastest way to reproduce a problem she hits without her sending you any data.
